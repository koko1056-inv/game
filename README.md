# 🌲 森を育てよう 〜林業経営シミュレーション〜

林業に関わる一連の流れ — **植林 → 育成 → 間伐 → 主伐 → 運搬・販売** — を遊びながら学べる、ブラウザ用シミュレーションゲームです。お金（経営）を回しながら、土地・人・機械への投資で事業を拡大していきます。

> ビルド不要。ブラウザで `index.html` を開くだけで遊べます。

## 遊び方

1. `index.html` をブラウザで開きます。
2. **空き地マス**をクリックして「🌱 苗木を植える」を選び、樹種（スギ・ヒノキ・カラマツ）を決めます。
3. 「⏭️ 次の季節へ」で時間を進めると木が成長します。
4. 木が育ったら **間伐（✂️）** で手入れし、**主伐（🪓）** で収穫して丸太を土場へ集めます。
5. 「🚚 木材を出荷する」で丸太を販売し、現金を得ます（市況で価格が変動）。
6. 稼いだお金で **土地の購入・作業員の雇用・林業機械の導入** をして経営を拡大しましょう。

## 学べる林業のポイント

- **再造林**：主伐したあとに植え直して森を持続させる考え方
- **間伐の役割**：混みすぎた木を間引き、残す木をよく育てる
- **土場と運搬**：丸太を集積してまとめて運ぶ効率の重要性
- **林業機械**：ハーベスタ等による生産性・安全性の向上
- **経営・市況・補助金**：価格変動や公的支援を踏まえた長期経営
- **環境価値**：森林のCO₂吸収・防災（緑のダム）

作業のたびに「作業日誌＆まめ知識」に解説が表示されます。
